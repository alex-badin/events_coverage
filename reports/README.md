# Reports & analysis read-outs

Rendered analyses of the framing data. Each is generated by a script in `generators/` from the
raw `data/interim/event_*_framing.jsonl` (no model calls). Published copies live on claude.ai
(default-private); regenerate locally to update.

> Read [`../docs/framing_readout_caveats.md`](../docs/framing_readout_caveats.md) first — it
> explains how an aggregate value is produced and the two ways meaning is lost (modal-role
> compression; role-from-text-regardless-of-voice).

## Regenerate

```bash
.venv/bin/python reports/generators/narrative_report.py   # writes reports/narrative_report.html
.venv/bin/python reports/generators/gen_distributions.py  # writes reports/field_distributions.html
.venv/bin/python reports/generators/build_explorer.py     # writes reports/raw_records.html
# clustering (two steps): embed once (caches to data/interim/framing_embeddings/), then cluster
.venv/bin/python reports/generators/embed_framings.py     # OpenAI text-embedding-3-large (cheap)
cd reports/generators && python build_cluster_report.py   # writes reports/cluster_report.html + reports/clusters/*.csv
cd reports/generators && python build_association_report.py  # writes reports/association_report.html (χ²/Cramér's V)
cd reports/generators && python run_stats.py              # same tests, console output
```

The raw explorer currently embeds Trump–Zelensky + Kursk only (size); edit its `EVENTS` list to
include others. To publish, open the generated HTML as a claude.ai artifact.

## What persists vs what doesn't

- **Durable (in repo):** raw model output (`data/interim/*.jsonl`), datasets (`data/processed/`),
  these generators, the docs.
- **Durable (in ~/.claude memory):** findings & constraints — `framing-pipeline`,
  `embedding-coverage-constraint`, `narrative-divergence-findings`.
- **Not durable:** the published artifacts are hosted on claude.ai (links above); the live
  session scratchpad is wiped between sessions. That's why the generators are copied here.
