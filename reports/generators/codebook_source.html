events_coverage · framing extraction instrument

The framing codebook

Eleven fields fill one record per news message. Each is defined once here — under its own schema name, grouped by the theory it comes from, with its allowed values and the distribution observed in the kursk_2025w11 pilot. One OpenAI gpt-5.5 call produces one record under a strict, Pydantic-backed schema.

11 fields 6 source groups 18 roles · 5 epistemic · 5 Semetko model gpt-5.5 · effort low observed: N=669 messages

A

Relevance gate

operational · not a framing theory

One boolean that decides whether the message is even in scope. It is not part of any framing theory — it keeps off-topic items in digests from contaminating the rest of the record.

on_eventboolrelevance
Source
Operational gate — not a framing construct.
Captures
Whether this message is substantively about the target event.
Values
true / false, with a verbatim Russian evidence span.
Coding
Mark false only when the text is really about something else — guards against digests that bundle unrelated items.
Observed
present 100% · flagged false 0 / 669
!Inert in this run. Zero messages were flagged false despite 21 digests in the kept set — the gate is not yet doing its job.
B

Shared substrate

named-entity & event extraction

Who and what — recorded before any framing is read off, and deliberately kept group-neutral. This is the common ground every outlet is talking about; the framing in groups C–F is what gets laid on top of it.

entities[]list of objNER
Source
Named-entity recognition.
Captures
The cast of actors named in the message.
Fields
mention

verbatim Russian surface form (e.g. «наши бойцы»)

canonical

stable English name for merging across messages → Russian Armed Forces

type

free-text category label (currently uncontrolled)

Values
Free text. canonical and type are not enums.
Coding
Name the actor, don't judge it — judgement belongs in moral_evaluation.
Observed
mean 8.5/msg · 786 distinct canonical (merged 988→786)
!type is uncontrolled and fragmented to 150+ strings with near-duplicates (military_unit, military unit, military_force…). Worth promoting to a small enum.

group-neutral English verb (e.g. took control of)

C

Entman's framing functions

Entman 1993

Entman defines framing as selecting some aspects of a perceived reality and making them more salient so as to perform up to four functions. Five fields map directly onto that definition: the four functions, plus the salience mechanism itself (emphasized).

problem_definitionstrfunction 1 · define the problem
Source
Entman 1993 — Function 1: define the problem.
Captures
What the event is framed as.
Values
Short English gloss + verbatim Russian evidence.
Coding
The headline category («liberation of Russian territory» vs «Russian assault on a town»), not a summary.
Observed
present 100% · evidence-grounded 88.5%
causal_attributionobjfunction 2 · diagnose the cause
Source
Entman 1993 — Function 2: diagnose the cause.
Captures
Who or what the text presents as the cause / initiator.
Fields
cause_entity

canonical entity, or null

mechanism

short English gloss of the causal story, or null

evidence

verbatim Russian quote, or null

Values
See fields; all three may be null.
Coding
Leans toward "the active agent," so read alongside moral_evaluation — not as blame on its own.
Observed
cause_entity present 80.7% · null 19.3%
moral_evaluation[]list of objfunction 3 · make a moral judgment
Source
Entman 1993 — Function 3: make a moral judgment.
Captures
The dramatic role each actor is cast in, plus signed stance toward it.
Fields
entity

canonical entity name

role

one of the 18-role inventory below

polarity

integer −2 … +2 — stance toward the entity

intensity

integer 0 … 2 — strength of that stance

evidence

verbatim Russian quote

Coding
Read as role × polarity, never role alone — a «victim» may be a defeated enemy carrying negative polarity.

D

Generic news frames

Semetko & Valkenburg 2000

Five recurring frames that journalism uses across any topic, validated by Semetko & Valkenburg (2000). Multi-label: a message can carry several, or none.

semetko5 × boolgeneric frames
Source
Semetko & Valkenburg 2000 — five generic news frames.
Captures
Which of the five frames the text actually performs.
Coding
Mark a frame present only if the text does that framing — not merely if the topic could be framed that way. Plus one evidence quote for the strongest frame.
Observed
mean 1.99 frames/msg · 66 messages carry none

the five frames   bar = share of messages where present

conflict82.8%554
responsibility75.6%506
human_interest22.4%150
morality16.3%109
economic_consequences1.3%9
conflict

disagreement/reproach between parties; two sides, winners vs losers

responsibility

attributes the cause or the solution to a government / group / individual

human_interest

personal/emotional angle: individual stories, eyewitnesses, suffering

morality

right vs wrong, moral prescriptions, faith, justice as virtue

economic_consequences

cost / gain / loss in money terms — prices, budgets, damage

!Near-degenerate on war coverage. conflict + responsibility blanket almost everything while economic_consequences is essentially silent — low discriminative power here, though it should separate outlets on economic events.
E

Word choice

lexical framing

The single loaded word an outlet chooses for an action — «освобождение» vs «оккупация» for the same event — captured verbatim with its slant. This is lexical framing: the same referent, opposite vocabulary.

action_labels[]list of objlexical framing
Source
Lexical framing — the loaded keywords/phrases an outlet selects (cf. Entman's "keywords, stock phrases").
Captures
The loaded term used for an action, and the slant it carries.
Fields
action

which action, short English

term

the EXACT Russian word/phrase used (e.g. «освобождение»)

valence

how the outlet loads the term: positive / negative / neutral

evidence

verbatim Russian quote

Values
valence ∈ positivenegativeneutral
Coding
term stays verbatim Russian; valence is the loading toward the outlet's own side; keep the up-to-5 most salient.
Observed
mean 3.5/msg (cap 5) · total 2,366 · 99.8% grounded — the cleanest field
positive59.1%1399
negative28.3%670
neutral12.6%297
F

Epistemic stance

evidentiality

How the message presents its core claim — as established fact, as someone else's claim, or as doubtful. Borrowed from linguistic evidentiality; it is about presentation, never about whether the claim is true.

epistemic_statusenumevidentiality
Source
Evidentiality (linguistics) — the stance a text takes toward its own claim.
Captures
How the message presents its core claim.
Values
One of five (single-valued) + evidence quote.
Coding
Exactly one value per message; the strongest state-vs-independent differentiator observed.
Observed
present 100% · evidence-grounded 77.6% (the weakest-grounded field)
attributed62.6%419
asserted34.2%229
hedged2.8%19
questioned0.3%2
denied0.0%0
asserted

stated as established fact in the outlet's own voice

attributed

explicitly sourced — «по данным Минобороны»

hedged

qualified / uncertain — «предположительно»

denied

presents the claim as false

questioned

casts doubt / raises it as a question

!Effectively binary here. asserted + attributed = 97% combined; denied never fires and questioned twice — the skepticism signal is thinner than the 5-value enum implies.
